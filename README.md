# Lavanda City Cafe — сайт-меню и панель управления

Меню на трёх языках (русский, казахский, английский), бизнес-ланч по дням недели,
кнопка «Показать официанту», панель управления на `/admin`.

Диск не нужен: меню и фотографии хранятся в объектном хранилище.

---

# Запуск через браузер, без терминала

## Шаг 1. Положить файлы в GitHub

1. Зарегистрируйтесь на github.com, если аккаунта нет.
2. Нажмите «+» вверху справа → New repository.
3. Имя: `lavanda-menu`. Оставьте Public. Нажмите Create repository.
4. На пустой странице репозитория нажмите «uploading an existing file».
5. Распакуйте архив на компьютере, откройте папку `lavanda-menu`
   и перетащите в браузер **всё её содержимое** — файлы и папки `public` и `seed`.
   Важно: перетаскивать надо то, что лежит ВНУТРИ папки, а не саму папку.
6. Внизу нажмите Commit changes.

Проверьте: в репозитории должны быть видны `server.js`, `package.json`,
`Dockerfile`, `fly.toml` и папки `public`, `seed`.

## Шаг 2. Создать приложение на Fly

1. Откройте https://fly.io/dashboard/personal/new
2. Нажмите кнопку подключения GitHub, разрешите доступ к репозиторию.
3. Выберите репозиторий `lavanda-menu`.
4. Имя приложения придумайте своё, например `lavanda-uralsk`.
   Адрес сайта будет `https://lavanda-uralsk.fly.dev`
5. Регион: Frankfurt (fra).
6. Запустите развёртывание и дождитесь окончания. Первый раз идёт 3–5 минут.

Если сборка упала — откройте лог и пришлите мне последние строки.

## Шаг 3. Подключить хранилище

1. В левом меню Fly выберите **Tigris Object Storage**.
2. Создайте бакет, привяжите его к приложению `lavanda-uralsk`.
   Доступ наружу открывать НЕ нужно: фотографии сайт отдаёт сам.
3. Fly сам пропишет приложению ключи:
   `BUCKET_NAME`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`,
   `AWS_ENDPOINT_URL_S3`, `AWS_REGION`. Трогать их не надо.

## Шаг 4. Задать пароль администратора

1. Откройте приложение → Secrets (или Settings → Secrets).
2. Добавьте `ADMIN_PASSWORD` — ваш пароль для входа в панель.
3. Добавьте `SESSION_SECRET` — длинная случайная строка, 40–60 символов,
   просто постучите по клавиатуре. Её никто не вводит, она нужна серверу.
4. После сохранения секретов приложение перезапустится само.

## Шаг 5. Проверить

1. `https://ваше-имя.fly.dev` — меню.
2. `https://ваше-имя.fly.dev/admin` — вход по паролю из шага 4.
3. В панели поменяйте цену любого блюда, сохраните,
   откройте меню в другой вкладке — цена новая.

## Дальнейшие изменения

Правите файл в GitHub через браузер → Fly пересобирает сайт сам.
Включается в приложении: Deployments → Settings → auto-deploy.

Меню и фотографии при этом не трогаются — они в хранилище, а не в коде.

# Что внутри

- `server.js` — сервер: меню, вход, сохранение, приём и отдача фотографий
- `public/index.html` — страница меню для гостей
- `public/admin.html` — панель управления
- `public/media/` — логотип, два ролика зала, кадр-заставка
- `seed/menu.json` — стартовое меню, кладётся в хранилище при первом запуске
- `Dockerfile`, `fly.toml` — как собирать и где запускать

## Что хранится в бакете

- `menu.json` — текущее меню
- `dishes/*.webp` — фотографии блюд
- `backups/menu-*.json` — копии перед каждым сохранением, последние 20

## Фотографии блюд

Грузите прямо с телефона, готовить ничего не надо: сервер развернёт снимок
по EXIF, обрежет в квадрат 900×900 и пережмёт в WEBP. Из 5 МБ получается 30–80 КБ.

Снимайте строго сверху, тарелка по центру, один тёмный фон, свет сбоку:
на сайте фото показывается в круге, углы кадра не попадут.

## Проверка у себя на компьютере

```
npm install
ADMIN_PASSWORD=test123 npm start
```
Откройте http://localhost:8080 — всё ляжет в папку `data`.

## Если что-то не так

- Логи приложения на Fly показывают ошибки сервера.
- Забыли пароль — поменяйте секрет `ADMIN_PASSWORD`, приложение перезапустится.
- Меню пустое и крутится занавес — не подключено хранилище, вернитесь к шагу 3.
- Сайт медленно открывается после простоя — в `fly.toml` замените
  `min_machines_running = 0` на `1`, тогда машина перестанет засыпать.
